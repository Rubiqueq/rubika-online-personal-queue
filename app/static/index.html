۱. ورود به حساب شخصی روبیکا

کد ورود فقط برای ورود به حساب خودتان استفاده می‌شود. نشست حساب صرفاً روی سرور شخصی ذخیره می‌شود؛ هرگز فایل نشست را در GitHub عمومی قرار ندهید.

۲. واردکردن مخاطبان Excel

ستون‌ها: phone,name,consent، برای هر ردیف باید رضایت گیرنده بله ثبت شده باشد. شماره‌های تکراری حذف می‌شوند. هیچ شماره‌ای بدون رضایت وارد صف نمی‌شود.

۳. متن و زمان‌بندی صف

«sent» به معنی پذیرش توسط سرور همراه با شناسه پیام است، نه تحویل یا خواندن. در پاسخ‌های مبهم، صف آن مورد را برای بررسی دستی نگه می‌دارد و خودکار تکرار نمی‌کند.
